# Commercial use · 商业使用

OpenLanguageKit is licensed under CC BY-NC 4.0, which does not allow commercial use. If you want to use it commercially, you need a separate paid licence from the author.

**Commercial use includes**, for example: selling or charging subscriptions for an app, course or service built on this material; using it inside a for-profit product or a paid training programme; using it to build products for paying clients.

**Not commercial**: personal learning, teaching your own students without selling the material itself, academic research, and non-profit community projects.

If you are unsure which side you are on, ask.

**How to ask**: open an issue in this repository titled "Commercial licence" with who you are and what you plan to build, or contact the author through the GitHub profile [@ywEdAi](https://github.com/ywEdAi). Please get the licence before you ship.
