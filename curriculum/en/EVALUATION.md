# 英语课程知识库 · 学习者画像排课审计（2026-11-08）

## 方法

我按六类学习者各排了一套课，写在 `tracks.json`，浏览页"课程方案"里可以看到：

| 方案 | 学习者 | 范围 | 新教知识点 |
| --- | --- | --- | ---: |
| `young-early` | 5–7 岁，尚未识字 | Pre-A1–A1 | 56 |
| `young-primary` | 8–12 岁，已识字 | A1–A2 | 151 |
| `teen` | 13–17 岁，在校、有升学考试 | 诊断 A2 → B1，部分 B2 | 174 |
| `adult-everyday` | 成人零基础，出行与在英语国家生活 | A1–A2，部分 B1 | 188 |
| `adult-work` | 上班族，已有 A2 | B1–B2，部分 C1 | 100 |
| `academic` | 升学、留学，已有 B1 | B2–C1 | 77 |

每排一套课，我都问三个问题：

1. 这类学习者需要的话题、功能和技能，知识库里有没有？
2. 不按默认路径的顺序排，先修关系还排得通吗？
3. 有没有某类内容，几套方案都缺？

第三个问题针对的是成类、成规律的缺口，比单个零散缺口更重要。

## 发现的问题（审计前 299 个知识点）

### 规律一：话题和词汇域只跟着 Core Inventory 走，缺了生活领域

Core Inventory 是语法和功能清单，只列出少数词汇域。所以知识库里没有以下话题：

- 天气
- 动物与自然
- 身体与健康
- 学校与课堂
- 运动与玩具
- 住房
- 钱与公共服务
- 人际关系
- 科技与网络
- 环境
- 商务

儿童课程和成人日常课程在第一阶段就排不下去。

**处理**：以 Threshold 1990 的 14 个交际主题（CEFR 2001 §4.2）和 CEFR 的四个领域（§4.1）作为话题分母，补了 11 个来源单元。CEFR 原文本轮仍未取得，这些单元标为"未核对"。

### 规律二：社交与态度功能只覆盖了问候和观点

缺的功能有：

- 致谢与道歉
- 祝贺与慰问
- 投诉
- 打电话
- 预约
- 紧急求助
- 劝告与使役（had better、make/let）

感受类功能原来最早在 B1，但儿童在 A1 就要说 I'm hungry。

**处理**：按 Threshold 的功能大类（socialising、attitudes、suasion）补了 3 个来源单元，对应 9 个知识点。

### 规律三：只有字母名称，没有"字母怎么读"

原补充类只覆盖字母名称、屈折拼写和标点。低龄学习者没有解码能力就无法开始阅读，成人遇到生词也读不出来。

**处理**：补了一整条自然拼读线，共 10 个知识点：

- 音素意识
- 单字母读音
- CVC 拼读
- 辅音组合
- 认读词
- 书写
- 长元音
- r 控制元音
- 多音节拆分
- 音标

此外补了 1 个查词典的策略知识点。

### 规律四：没有 Pre-A1 和低龄入口活动

Core Inventory 从 A1 开始。听指令做动作、听故事、看图说话这三类低龄核心活动，原来没有对应的知识点。

**处理**：
- 补了 3 个活动知识点，来源标为 CEFR Companion Volume 2020 的 Pre-A1，原文未取得。
- 课程方案允许重新排序，例如 `young-early` 把字母放在有了口头词汇之后。

### 规律五：高频句型有零星漏洞

排课时发现这些没有知识点：

- 反身代词
- 不定代词
- 主语疑问句
- 形式主语 it
- 时间从句（when/until + 现在时表将来）
- so/such
- be/get used to
- prefer / would rather
- 替代与省略
- unless / provided / in case

它们都是排一节具体的课时才暴露出来的，因为 Core Inventory 的条目名本身不会提示它们缺失。

**处理**：
- 补了 10 个知识点。
- 其中 so/such 本来就在 Core Inventory ci:163@B1 里，原先被 too/enough 一个知识点吞掉了。已拆开，并让两者都映射到这个来源单元。

### 规律六：先修关系在默认路径里成立，换顺序就排不通

在默认路径里检查先修，只能证明这一条路径成立。换成职场、学术方案后，发现两条"必须先修"其实是话题依赖，而不是能力依赖：

- 读文章 → 新闻话题
- 评论 → 谈电影与书

这两条已改为"有帮助"。

**处理**：`check.py` 现在也对每套课程方案做先修检查。默认已掌握的部分用 `assumes` 声明。

## 结果

| | 审计前 | 审计后 |
| --- | ---: | ---: |
| 来源单元 | 398 | 418 |
| 知识点 | 299 | 353 |
| 路径单元 | 51 | 60 |
| 必要先修 / 有帮助先修 | 349 / 46 | 398 / 94 |

`python3 curriculum/check.py en` 的结果是 0 个错误、0 个警告，六套方案的先修全部排得通。新增的 54 个知识点都有完整内容（说明、形式、例句、掌握标准、题型、常见错误、边界）。

## 仍未解决、需要知道的

1. **词汇层只到"词汇集"，没有逐词清单。** 一个 Duolingo 式产品最终要追踪每个词，但知识点里的 `forms` 只给代表词。下一步应该接一个分级词表做词条层，每个词挂到对应的词汇或话题知识点上。English Vocabulary Profile 是授权资源，需要另外取得。
2. **没有 C2。** 六套方案都止于 C1。
3. **社会文化知识只覆盖了礼貌、语域和变体。** 节日习俗、禁忌等 CEFR §5.1.1.2 的内容没有单列。日语这部分更重要，会在日语里先做出结构，再回补英语。
4. **补充来源都标为"未核对"。** CEFR 2001、CV 2020 原文都返回 403。拿到原文后应逐条核对 `sup:*` 的章节号，并用 CV 的 Pre-A1 和在线互动描述校准级别。
5. **考试题型没有挂进来。** 青少年方案提到的完形、阅读等题型，可以在 `itemTypes` 之上另加一层考试映射。
6. **课程方案是编辑性设计。** 阶段划分和取舍没有经过教师审核或学习者试验。
